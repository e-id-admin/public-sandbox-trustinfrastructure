# Deprecated: Public Sandbox Trust Infrastructure

## Update regarding Public Beta

The Public Sandbox Trust Infrastructure has been replaced with the [**swiyu Public Beta Trust Infrastructure**](https://github.com/swiyu-admin-ch). Future ecosystem participants can now run and integrate their use cases on the technologies that will be used for the initial productive implementation of the e-ID and its trust-infrastructure.

Please consult the [swiyu technical documentation website](https://swiyu-admin-ch.github.io/) for further details on technology and standards and the new [cookbooks](https://swiyu-admin-ch.github.io/cookbooks/) for the onboarding to the Public Beta Trust Infrastructure.
